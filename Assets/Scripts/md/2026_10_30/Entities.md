# Сущности и их уровни (Entities Architecture)

**Проект:** LunaticMagicV3  
**Назначение:** Архитектура сущности, 4 уровня материализации (L1–L4) и внутреннее устройство компонентов.

---

## 1. Концепция Сущности

Сущность (`EntityRuntime`) — это универсальный игровой актор (Игрок, Орк, Рыба, Дрон, Катсцена). 
Она не привязана жестко к Unity `GameObject`, а существует независимо в оперативной памяти и материализуется в сцене по мере приближения к игроку.

---

## 2. Четыре уровня материализации (L1–L4)

Сущность существует на одном из четырех уровней в зависимости от расстояния до точки фокуса:

```
┌─────────────────────────────────────────────────────────────────────────────┐
│ УРОВЕНЬ 1 (L1): Данные и Виртуальная симуляция (Pure Data & A-Life)        │
│   • Чистый C# класс EntityRuntime в оперативной памяти                      │
│   • Хранит ID, координаты, HP, инвентарь, квесты, баффы                    │
│   • НЕТ GameObject на сцене Unity, НЕТ физики, НЕТ рендеринга               │
│   • Для стриминга представлена точкой в BoundingSphere                      │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ Вход в Зону физ. тела (~100м)
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ УРОВЕНЬ 2 (L2): Замороженное физическое тело (isKinematic = true)           │
│   • Появляется легкий Unity GameObject с коллайдером                        │
│   • Rigidbody.isKinematic = true (физический движок не считает гравитацию)  │
│   • Занимает место в пространстве, доступен для триггеров и рейкастов       │
│   • Гарантирует, что моб не провалится в террейн до включения полной физики │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ Вход в Зону активной физики (~50м)
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ УРОВЕНЬ 3 (L3): Размороженная активная физика (isKinematic = false)         │
│   • Rigidbody.isKinematic = false / активен CharacterController             │
│   • Включается локальный NavMeshAgent / физическое расталкивание            │
│   • Обработка гравитации, получение ударов, толчков, рэгдолл                │
└──────────────────────────────────────┬──────────────────────────────────────┘
                                       │ Вход в Зону видимости (~30м)
                                       ▼
┌─────────────────────────────────────────────────────────────────────────────┐
│ УРОВЕНЬ 4 (L4): Полное визуальное представление (Visuals & 3D Model)       │
│   • Подключение 3D-меша / VRM 1.0 модели из пула                            │
│   • Включение Animator, шейдеров MToon, физики волос/ткани                  │
│   • Отображение оружия в руках, VFX частиц и плашки здоровья (HUD/UI)       │
└─────────────────────────────────────────────────────────────────────────────┘
```

### Лесенка переходов (Runtime Tier Pipeline)
Сущность не может перепрыгивать через уровни хаотично — переход всегда идет по цепочке:
$$L1 \rightleftarrows L2 \rightleftarrows L3 \rightleftarrows L4$$

* **L1 $\rightarrow$ L2:** Выделение легковесного `GameObject` с коллайдером (`isKinematic = true`).
* **L2 $\rightarrow$ L3:** Активация локомоции, `isKinematic = false`, включение гравитации и NavMesh.
* **L3 $\rightarrow$ L4:** Прикрепление 3D-модели (VRM) из пула, запуск аниматора.
* **L4 $\rightarrow$ L3:** Возврат 3D-модели в пул, выключение аниматора (физика еще жива).
* **L3 $\rightarrow$ L2:** Заморозка физики (`isKinematic = true`), остановка NavMesh.
* **L2 $\rightarrow$ L1:** Уничтожение/возврат в пул физического `GameObject`. Сущность снова чистый C# объект.

## 3. Внутреннее устройство сущности

Сущность состоит из модульных, независимых компонентов:

1. **Приемник команд (`ICommandReceiver`) — "Руль":**
   * Универсальный порт приема абстрактных команд (`Move(dir)`, `Look(dir)`, `ExecuteAction(slot)`, `Interact()`).
   * Сущность сама знает, как исполнить команду (человек идет по земле, рыба плывет в толще воды).

2. **Мозг (Brain / Controller) — "Источник команд":**
   * Ввод игрока (клавиатура/мышь) или конкретный ИИ (ИИ рыбы, ИИ орка, ИИ дрона).
   * Не управляет костями напрямую, а только шлет команды в `ICommandReceiver`.

3. **Двигатель (Locomotion / Motor):**
   * Физический компонент (CharacterController / Rigidbody), активен на L3/L4.
   * Исполняет перемещение по правилам гравитации и террейна.

4. **Система Способностей и Эффектов (Actions & Effects):**
   * Слоты действий (Slot 0..N): привязка навыков к кнопкам/командам.
   * Эффекты и кулдауны: любые задержки (включая 200 мс прыжка или 900 мс удара) — это временные эффекты с таймерами (`Effect`), а не громоздкие стейт-машины.
   * Вычисляемый стейт (Computed State): `CanJump`, `CanCast` вычисляются реактивно от наличия эффектов/тегов блокировки.

5. **Виртуальная камера:**
   * Ракурс, FOV и настройки обзора от 1-го/3-го лица.
   * Активируется только когда сущность получает системный фокус (`IFocusable`).
