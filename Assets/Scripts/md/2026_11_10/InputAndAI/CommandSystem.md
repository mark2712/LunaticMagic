# Подсистема: Управление, Ввод и ИИ (Command System)

**Папка документации:** `Assets/Scripts/md/2026_11_10/InputAndAI/`

---

## 1. Архитектурный принцип: Источник $\rightarrow$ Приёмник команд

В игре строго разделены генератор намерений («Мозг») и исполнитель намерений («Руль»):

```
┌──────────────────────────────────────┐     ┌──────────────────────────────────────┐
│       Ввод Игрока (PlayerBrain)       │     │          Искусственный Интеллект     │
│   (Клавиатура / Мышь / Геймпад)      │     │              (AIBrain)               │
└──────────────────┬───────────────────┘     └──────────────────┬───────────────────┘
                   │                                            │
                   │           Универсальные команды             │
                   └───────────────────┬────────────────────────┘
                                       ▼
                   ┌────────────────────────────────────────────┐
                   │    Приёмник Команд (ICommandReceiver)      │
                   │              "Руль Сущности"               │
                   └───────────────────┬────────────────────────┘
                                       ▼
                   ┌────────────────────────────────────────────┐
                   │   Исполнение (Локомоция, Мотор, Скиллы)    │
                   │ • Человек: шагает по земле                 │
                   │ • Рыба: плывёт в толще воды                │
                   │ • Дрон: летит по воздуху                   │
                   └────────────────────────────────────────────┘
```

---

## 2. Равноправие Игрока и ИИ

* Игрок физически ничем не отличается от NPC. Ввод игрока и алгоритмы ИИ — это равноправные источники команд.
* Если у орка-NPC стоит задача «следовать из А в Б», его мозг шлёт команды движения по координатам NavMesh (или симулирует шаги вне сцены на L1).
* Если в этого же орка вселился игрок, его мозг подменяется на `PlayerBrain`, и команды движения начинают идти с клавиатуры игрока.

---

## 3. Абстрактные намерения и слоты действий

* Источник команд не управляет напрямую анимациями или физическими силами. Он передаёт абстрактные намерения:
  * `Move(direction)`
  * `Look(direction)`
  * `Interact()`
  * `ExecuteAction(slotIndex)`
* Каждая сущность сама транслирует нажатие слота на своё доступное действие (нажатие `Slot 0` у Орка активирует взмах дубиной, у Мага — бросок огненного шара, у Дрона — вспышку прожектора).
